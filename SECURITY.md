# Security

ADTL is **experimental**. It is a personal open-source project built on draft MCP proposals, and it is not a security guarantee. Don't rely on it as the only protection for production systems.

## Reporting a problem

If you find a way around ADTL, for example a tool call that should have been blocked, a label that can be forged or dropped, or a crash that makes the gateway fail open, please report it privately:

1. Go to the repository's **Security** tab.
2. Click **Report a vulnerability**.

Please don't open a public issue for security problems. Include the ADTL version, your `adtl.yaml` (with secrets removed), and the steps to reproduce.

This is a hobby project, so replies may take a few days. Thank you for helping make it better.

## Supported versions

Only the latest `0.x` release gets fixes.
